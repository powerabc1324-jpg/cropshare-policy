CropShare 개인정보처리방침

최종 수정일: 2026-08-04

CropShare(이하 "앱")는 사용자가 지정한 화면 영역을 같은 Wi-Fi 네트워크에 있는 다른 기기로 보내는 도구입니다. 이 문서는 앱이 어떤 정보를 다루고 다루지 않는지를 설명합니다.

1. 요약

  • 앱은 사용자 정보를 수집하지 않습니다. 개발자가 운영하는 서버가 없습니다.
  • 화면 내용은 같은 네트워크 안에서만 오가며, 외부로 전송되거나 저장되지 않습니다.
  • 광고 식별자, 위치, 연락처, 계정 정보를 사용하지 않습니다.
  • 분석 도구나 광고 SDK를 넣지 않았습니다.

2. 앱이 다루는 정보

화면 내용

공유를 시작하면 사용자가 지정한 사각형 영역만 캡처되어 전송됩니다. 지정한 영역 밖의 화면은 캡처되지 않습니다.

전송은 사용자의 기기에서 같은 네트워크의 수신 기기로 직접 이루어집니다. 중간 서버를 거치지 않으며, 개발자는 그 내용을 볼 수 없고 보관하지도 않습니다. 공유를 멈추면 전송된 화면은 어디에도 남지 않습니다.

접속 번호

공유를 시작할 때마다 여섯 자리 번호가 새로 만들어집니다. 이 번호를 아는 기기만 화면을 볼 수 있습니다. 번호는 기기 메모리에만 있으며 공유를 끝내면 사라집니다.

기기 이름

수신 기기가 주변에서 찾을 수 있도록, 공유 중에는 기기 모델명(예: SM-X910)이 같은 네트워크에 알려집니다. 이 정보는 네트워크 밖으로 나가지 않으며 공유를 끝내면 중단됩니다.

카메라 (수신 앱)

QR 코드를 읽을 때만 카메라를 사용합니다. 촬영한 영상은 화면에 표시되는 즉시 버려지며, 저장하거나 전송하지 않습니다.

기기에 저장되는 설정

저장 내용목적위치
마지막에 사용한 공유 영역 크기와 비율 다음 실행에서 같은 크기를 다시 쓰기 위해 기기 내부 저장소
최근 접속한 주소 (수신 앱) 같은 기기에 다시 접속하기 쉽도록 기기 내부 저장소

두 항목 모두 기기 안에만 있으며, 앱을 삭제하면 함께 지워집니다.

4. 보안에 관한 안내

전송 내용은 암호화되지 않습니다. 앱은 같은 네트워크 안에서 쓰는 것을 전제로 만들어졌고, 접속 번호로 접근을 제한합니다. 다만 같은 네트워크를 관리하는 사람이나 네트워크 장비는 오가는 내용을 볼 수 있습니다.

카페, 공항, 호텔처럼 모르는 사람과 함께 쓰는 Wi-Fi에서는 민감한 내용을 공유하지 마세요. 회사나 학교, 집처럼 신뢰할 수 있는 네트워크에서 사용하시기를 권합니다.

접속 번호는 여러 번 틀리면 일정 시간 접속이 막힙니다. 공유를 시작할 때마다 번호가 새로 만들어지므로 지난번 번호로는 접속할 수 없습니다.

5. 아동

앱은 특정 연령대를 대상으로 하지 않으며, 나이를 포함한 어떤 개인정보도 수집하지 않습니다.

6. 제3자 제공

개발자가 수집하는 정보가 없으므로 제3자에게 제공하거나 판매하는 정보도 없습니다. 앱에는 광고나 분석 도구가 들어 있지 않습니다.

7. 방침 변경

앱에 기능이 추가되어 다루는 정보가 달라지면 이 문서를 고치고 최종 수정일을 바꿉니다. 중요한 변경은 앱 안에서도 알립니다.

CropShare Privacy Policy

Last updated: 2026-08-04

CropShare ("the app") sends a screen area you choose to other devices on the same Wi-Fi network. This document explains what the app does and does not do with information.

1. Summary

  • The app does not collect any user information. There is no server operated by the developer.
  • Screen content travels only within your local network and is never sent or stored elsewhere.
  • No advertising identifiers, location, contacts, or account information are used.
  • No analytics or advertising SDKs are included.

2. Information the app handles

Screen content

When sharing starts, only the rectangular area you selected is captured and sent. Anything outside that area is not captured.

Transmission happens directly from your device to viewing devices on the same network. It does not pass through any intermediate server. The developer cannot see or store it. When you stop sharing, nothing remains anywhere.

Connection code

A new six-digit code is created each time you start sharing. Only devices that know the code can view your screen. The code exists only in device memory and disappears when sharing ends.

Device name

While sharing, your device model name (for example SM-X910) is announced on the local network so viewers can find it. This never leaves the network and stops when sharing ends.

Camera (viewer app)

The camera is used only to read QR codes. The camera feed is discarded as soon as it is shown and is never stored or transmitted.

Both stay on your device and are removed when you uninstall the app.

4. Security notice

Transmitted content is not encrypted. The app is designed for use within a network you trust, and access is limited by the connection code. However, whoever manages that network, and the network equipment itself, can observe the traffic.

Do not share sensitive content on Wi-Fi you share with strangers, such as cafés, airports, or hotels. Use it on networks you trust, such as your workplace, school, or home.

Repeated wrong codes block connections for a while. A new code is generated each time sharing starts, so previous codes no longer work.

5. Children

The app is not directed at any particular age group and collects no personal information, including age.

6. Sharing with third parties

Because the developer collects nothing, there is nothing to share or sell. The app contains no advertising or analytics components.

7. Changes to this policy

If new features change what the app handles, this document will be updated and the date above changed. Significant changes will also be announced inside the app.
